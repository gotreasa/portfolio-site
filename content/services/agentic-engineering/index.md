I build AI agent tooling on Claude Code for a team's software delivery.

gSmith, the curriculum authoring and review toolkit I built while developing course material for a Fortune 100 insurer's upskilling programme, is now used by other authors: with it, a module that would have taken a week to write and review could be done in a day, depending on complexity. Vita, an AI job-application assistant I built for the contractors at the BriX partnership, writes only from what each person has actually done, and the owner and every contractor in the partnership use it.

I built both with nWave, the BriX partnership's AI-agent delivery methodology, which I contribute to, and used it to rewrite jest-cucumber-fusion, an open-source package I took over and publish as @g_package/jest-cucumber-fusion.
